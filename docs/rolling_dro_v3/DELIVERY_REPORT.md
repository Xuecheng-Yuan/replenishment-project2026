服务水平不再使用销量/需求选参。所有SKU每天期末严格判断库存>0，分母6000×28＝168,000；期末恰好为0计为0。题图每周期一天，补货提前期1，每次预测4天且执行最近1天。失销不结转，测试Period_1重新起算。

训练模型拟合第29–60天，在第1–28天重启验证中选取正库存服务95%–95.5%的候选，按库存需求比最小选参。保持已校准的模型和残差样本直接用于测试，不在选参后重新拟合。前向折仅作时间外推诊断。SAA和(s,S)采用额外训练校准倍率κ；三种DRO仍按特征聚类、不分组、爆品/长尾分组。

10项模型测试通过，库存守恒、提前期、失销、整数订单及正库存指标检查通过。完整CSV、gzip轨迹、四期预测、五策略订单、冻结参数、聚类画像及SHA256清单已全量更新。历史版本曾使用测试集诊断偏差，本次属于修订后的重复评估。
