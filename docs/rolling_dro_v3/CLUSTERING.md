# 特征聚类依据与实现

当前聚类以训练集中的需求形态与20个原始特征为依据。它将预测误差风险相近的SKU放在同组，共享相对预测误差样本并计算鲁棒补货倍率。本次测试中六类聚类的库存需求比低于爆品/长尾二分，但两者均高于传统(s,S)。

## 输入特征

记第i个SKU训练需求为$y_{it}$，令$\mu_i=\max(\operatorname{mean}_t y_{it},1)$。每个SKU提取以下5项：

| 输入 | 代码中的定义 | 库存解释 |
|---|---|---|
| 需求水平 | $\log(1+\mu_i)$ | 控制规模差异；对数减轻爆品极大值的影响 |
| 相对波动 | $\log(1+\operatorname{std}_t(y_{it})/\mu_i)$ | 表示需求相对于自身规模的波动 |
| 零需求比例 | $\operatorname{mean}_t\mathbf{1}(y_{it}=0)$ | 描述间歇性需求 |
| 上尾风险 | $\log(1+Q_{0.95}(y_i)/\mu_i)$ | 描述高需求相对日常需求的幅度 |
| 前后趋势 | $\log(1+\operatorname{mean}(y_{i,53:60})/\max(\operatorname{mean}(y_{i,29:36}),1))$ | 描述训练期初末的需求变化 |

20个原始特征分别取训练期均值，得到SKU×20矩阵，按列在6000个SKU间标准化，用SVD实现PCA，保留前三个主成分。三个主成分再次标准化并乘0.5。五个需求指标各自标准化后与三个主成分拼接，最终形成SKU×8聚类矩阵。

原始特征只给出x1至x20的名称，没有业务含义字典。这里通过PCA利用其统计结构，没有赋予主成分未经验证的业务含义。20个特征使用训练期均值，未直接利用其完整时间变化形态。

## 聚类算法与选择依据

使用欧氏距离K-means，K固定为6。随机种子20260929，尝试8次不同初始中心，每次最多60次迭代，保留类内平方距离之和最小的结果。

**K=6、保留3个主成分和权重0.5都是本版预设的建模选择。** 当前流水线没有对K或权重做训练内部网格选择，也没有用轮廓系数、肘部图或聚类稳定性检验确认6为最优。因此可称为“基于特征的六类聚类方案”，不能称为“数据自动选出的最优六类”。

最终测试使用训练第29–60天的拟合块生成并固定标签，测试特征及未来测试需求不参与聚类。训练验证时，前向折与重启折分别使用各自拟合块重新聚类。残差序列采用扩展窗口拟合外预测；组标签由对应拟合块生成，并非每个残差预测时点都重新估计标签。

## 如何进入决策

点预测候选包括SKU趋势与簇级趋势的混合。当前训练验证选出blend=1，因此最终点预测使用SKU自身趋势，最近3期已观测需求做加性偏差修正。

对每个SKU、每个拟合外预测周期构造相对误差$R_{it}=y_{it}/\max(\widehat y_{it},1)$；同组SKU的R合并成经验样本，构造W∞邻域，求满足最坏正库存概率约束的最小倍率$z_g$。SKU仍使用自己的点预测：整数补货目标为$\lfloor z_{g(i)}\widehat y_{i,t+1}\rfloor+1$。不分组DRO将全部SKU放在一组；爆品/长尾DRO使用原始类别标签形成两组。
