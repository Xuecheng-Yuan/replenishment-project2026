# 均值–方差补货 Baseline

## 1. 研究目标

本 baseline 用 60 期训练需求确定每个 SKU 的静态补货目标，并在模型冻结后用 28 期测试数据评价服务水平和周转率。它是后续时间序列、机器学习和决策导向模型的统一比较基准。

核心纪律是：test 只承担最终评价功能，不参与模型估计、参数选择、阈值选择或方法修改。

## 2. 数据使用边界

| 阶段 | 数据 | 时期 | 允许用途 | 禁止用途 |
|---|---|---:|---|---|
| 初始估计 | train | 1–42 | 估计各 SKU 需求均值和标准差 | 读取 test、随机打乱时间 |
| 内部验证 | train | 43–60 | 选择共同安全系数 `z` | 修改模型结构以迎合 test |
| 最终重估 | train | 1–60 | 在 `z` 固定后重估最终均值和标准差 | 重新选择 `z` |
| 最终评价 | test | 1–28 | 计算服务水平、库存和周转率 | 拟合、调参、阈值选择 |

train 与 test 中 SKU 相同并不构成泄漏。泄漏发生在 test 的需求、库存结果或评价指标影响模型参数时。当前流水线通过接口和执行顺序阻断这种回流。

## 3. 库存系统假设

1. 单级库存系统，每个 SKU 独立补货。
2. 提前期固定为一个时期。
3. 每期期初接收此前订单，随后需求发生，最后下达新订单。
4. 未满足需求记为 lost sales，不结转欠单。
5. 当前没有固定订货成本、容量、预算或最小起订量约束。
6. 因为没有固定订货成本，经典 `(s,S)` 策略退化为 `s=S` 的 base-stock 策略。

## 4. 参数估计与策略公式

令训练估计窗口为 `T_fit={1,...,42}`。对 SKU `i`：

```text
mean_i = T_fit 中需求的样本均值
std_i  = T_fit 中需求的样本标准差（ddof=1）
```

给定提前期 `L` 和候选安全系数 `z`：

```text
B_i(z) = ceil(mean_i × L + z × std_i × sqrt(L))
s_i(z) = S_i(z) = B_i(z)
```

程序在 `[0, 4]` 上以 `0.05` 为步长从小到大搜索 `z`。对每个候选，在 train 第 43–60 期进行库存仿真，选择第一个使总体服务水平达到 95% 的候选。如果搜索上限仍未达到 95%，保留上限 `z=4` 并明确报告未达标结果。

选定 `z` 后，用完整 60 期 train 重新计算 `mean_i` 和 `std_i`，再生成最终目标库存。这个重估过程仍然不读取 test。

## 5. 逐期库存流转

令 `H_i,t` 为满足第 `t` 期需求后的期末库存，`A_i,t` 为期初到货，`Q_i,t` 为期末订单，`D_i,t` 为需求，`Y_i,t` 为销售。

```text
A_i,1 = 0
A_i,t = Q_i,t-1, t >= 2

Y_i,t = min(D_i,t, H_i,t-1 + A_i,t)
H_i,t = H_i,t-1 + A_i,t - Y_i,t

库存位置 = H_i,t + 尚未到货的在途库存
若库存位置 <= s_i：Q_i,t = max(0, S_i - 库存位置)
否则：Q_i,t = 0
```

test 第一时期初现货库存来自 test 工作簿的 `initial_inventory`。模型不能根据 test 第一期需求预先补货。

## 6. 指标定义

总体服务水平：

```text
overall_service_level = Σ销售量 / Σ需求量
```

该指标按需求量加权，不是 6,000 个 SKU 服务水平的简单平均。

SKU 95% 达标比例：

```text
item_service_level_95_share
= 服务水平不低于 95% 的 SKU 数 / SKU 总数
```

平均总期末库存：

```text
average_total_ending_inventory
= 各测试期全部 SKU 期末库存总和的时间平均
```

总体周转率：

```text
overall_turnover
= 测试窗口总销售量 / 平均总期末库存
```

当前周转率覆盖完整 28 期窗口，不年化。

爆品和长尾品的分组服务率：

```text
category_service_level
= 该类别总销售量 / 该类别总需求量
```

爆品和长尾品的分组周转率：

```text
category_turnover
= 该类别测试窗口总销售量 / 该类别平均总期末库存
```

上述指标均先在类别内汇总分子和分母，再计算比率，不使用 SKU 指标的简单平均。当前数据包含 480 个爆品和 5,520 个长尾品；train/test 中同一 SKU 的类别必须一致。

## 7. 数据质量与可复现性检查

运行前自动检查：

- train 必须恰好有 60 个连续时期，test 必须恰好有 28 个连续时期；
- 每个工作表只能有一个 `demand_t` 字段；
- `item_id` 不能为空或重复；
- 各期 SKU 集合必须完整；
- 需求与初始库存必须是非负数且无缺失；
- train/test 的 SKU 集合必须一致；
- 策略参数必须满足 `S >= s >= 0`；
- 输出保存原始 Excel 的 SHA-256 指纹。

## 8. 已知局限

- 静态目标库存无法快速适应 train 与 test 之间的需求水平变化。
- 所有 SKU 共用一个 `z`，没有按品类或需求波动分层。
- 当前目标是总体服务水平达到 95%，不能保证每个 SKU 都达到 95%。
- 周转率没有年化，不能直接与不同测试窗口长度的研究比较。
- 当前没有持有成本、缺货成本和订货成本，因此 baseline 不是完整成本最优策略。
