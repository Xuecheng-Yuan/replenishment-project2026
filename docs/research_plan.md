## 下一阶段候选

1. 在 baseline 确认后建立滚动时间序列强基准。
2. 讨论总体 95% 服务水平是否需要增加 SKU 级公平性约束。
3. 明确后续模型能否使用滞后 `x1`–`x20`，以及这些字段在真实决策时的可见时间。
4. 为需求分布漂移设计滚动更新、加权历史或鲁棒安全库存。

## 统一实验原则

1. 所有模型按时间切分，不随机混合过去和未来。
2. test 不参与模型选择、超参数选择、安全系数选择或特征筛选。
3. 所有模型使用同一库存事件顺序和评价器。
4. 先报告服务水平是否达标，再比较库存和周转率。
5. 每次实验保存配置、数据指纹、代码版本和结果摘要。
