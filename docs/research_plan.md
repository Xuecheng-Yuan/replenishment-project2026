# 研究计划

- [x] 明确目标为最小化总期末库存除以总需求。
- [x] 明确正式约束为无缺货SKU-时期比例不低于95%。

- [x] 每次生成4期计划，只执行第一期订单。
- [x] 使用train估计需求分布并选择安全系数，test不参与调参。
- [x] 在test前4期与完整28期报告统一指标。

## 下一阶段

1. 由研究者审核数学口径、冷启动解释和当前结果。
2. 在统一库存评价器下建立机器学习需求预测方法。
3. 比较problem-based方法与机器学习方法的前4期和28期表现。
4. 所有方法先满足 $SL^{NS}\ge95\%$，再比较库存需求比。

## 统一实验原则

1. train用于拟合、调参和内部验证；test只用于冻结后的最终评价。
2. 决策时只能使用当时已经可见的信息，不能读取test未来需求。
3. 全部方法使用相同的到货—需求—下单事件顺序。
4. 同时报告总体、爆品和长尾品结果，避免总体指标掩盖重要类别。
5. 提交前运行测试、检查公式与代码一致性，并扫描隐私信息。
