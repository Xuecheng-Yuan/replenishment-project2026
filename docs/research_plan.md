# 研究计划

## 研究问题

待明确：在给定需求历史、库存约束和成本参数的条件下，如何联合需求预测与补货决策，使测试期总成本下降并保持目标服务水平？

## 基准方法

- 朴素需求预测与固定安全库存。
- 经典时间序列或机器学习预测后接补货优化。
- 后续候选：鲁棒优化、分布鲁棒优化、SPO/SPO+ 或端到端决策学习。

## 评价指标

- 预测层：MAE、RMSE、WAPE 或适合当前数据的尺度无关指标。
- 决策层：总成本、持有成本、缺货成本、订货成本、缺货率、填充率和服务水平。
- 工程层：训练时间、推理时间、稳定性和可复现性。

## 实验原则

1. 严格按时间切分训练、验证和测试集，避免未来信息泄漏。
2. 所有方法使用相同的数据切分、成本参数和评价器。
3. 每个实验固定随机种子，并保存配置、代码版本和结果摘要。
4. 先建立简单且可信的基线，再增加复杂模型。
