新版如何使用训练60期和独立测试28期

候选参数只在训练文件内部比较。三轮拟合都只看当时已有的历史，验证段依次向前。验证需求发生之后可以进入下一天预测的观测历史，不能提前进入当次预测。

第1轮
拟合：训练1–24期
验证：训练25–36期

第2轮
拟合：训练1–36期
验证：训练37–48期

第3轮
拟合：训练1–48期
验证：训练49–60期

每折验证承接该候选在拟合历史回放得到的期末库存和在途，只统计后续12期验证成绩。用于初始化库存的历史回放使用当折拟合器，与样本外验证段分别解读。

综合三轮成绩选定参数后，重新用训练文件全部1–60期拟合预测模型、特征聚类和训练残差。最后读取独立的 replenishment_test.xlsx，Period_1重新起算、恢复原始库存且没有初始在途，完整测试28期。测试未来需求不参与选参。

目标与服务口径

min J = Σi,tIit / Σi,tdit
P = Σi,t1{Iit > 0} / (N × T)，目标95% ≤ P ≤ 95.5%
FR = Σi,tsalesit / Σi,tdit

新版以总体6000种商品的 P 为服务指标；FR 另外报告。库存恰好卖完时 P 记0，FR仍可能为100%。先数每个商品期末是否有库存，再求比例；仓库总库存大于0不能代替 P。

J 是库存需求比，越低越好。常规库存周转率通常以销量或销售成本除以平均库存，方向和 J 不同。

每天发生什么

Ait = Ii,t−1 + qi,t−1
salesit = min(Ait, dit)
Iit = max(Ait − dit, 0)，lostit = max(dit − Ait, 0)

到货提前期为1，缺货丢失、不结转。当天需求发生后形成未来四期预测和补货计划，只下达第一笔订单 qit，它在下一期需求发生前到货。计划中的后三笔订单会在后续日期重新计算。首期没有初始在途。

水位公式与适用范围

令 k = ceil(βM)，z = r(k) + ε，S = floor(fz) + 1。在这个等权样本、W∞矩形球、未缩放水位的教学设置中，至少前 k 个样本的全部允许需求都严格低于 S，因而最坏正库存概率至少为 k/M ≥ β。

项目还从训练验证中选择倍率 κ，使用 S = floor(fκz) + 1。κ 小于1会改变上述保证，内部 β 不能直接解释成最终测试服务水平。实际达标情况由全部商品的真实 P 检验。

爆品/长尾 DRO 按商品品类共享残差，特征聚类 DRO 按训练得到的聚类共享残差，不分组 DRO 使用统一残差池。预测输入和四期滚动机制一致，残差池及风险参数不同。

项目实际区间 RO · 自动读取冻结参数

实际 RO 以训练相对残差均值 μ、标准差 σ 和宽度 Γ 构造需求集合：r ∈ [max(0, μ−Γσ), μ+Γσ]。它与上方教学 RO 的“样本区间并集”有不同的集合定义。

新版整数目标 SRO = floor(f × (μ+Γσ)) + 1。历史数量满足率版保留其数量倍率 βRO，按差额向上取整。Γ 控制区间宽度，没有四期共享预算的含义。
