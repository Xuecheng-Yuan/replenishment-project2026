## 目标、服务口径与库存流转

最小化 $J=\sum_{i,t}I_{it}/\sum_{i,t}d_{it}$。这是累计期末库存与需求之比，越低越好；并非通常定义的销售/平均库存周转次数。
需求满足率 $F=\sum s_{it}/\sum d_{it}$；正库存天数比例 $P=\sum\mathbf1\{I_{it}>0\}/(NT)$。
本版服务约束为 F≥95%，P为补充指标。
$a_{it}=I_{i,t-1}+q_{i,t-1}$，$s_{it}=\min(a_{it},d_{it})$，$I_{it}=(a_{it}-d_{it})_+$，$\ell_{it}=d_{it}-s_{it}$。
提前期为1；期末观察需求后下单，下一期需求前到货。缺货直接丢失，不递延。每次形成未来四期预测与补货计划，仅执行第一期订单，其余在下次滚动重算。初始库存与零初始在途量沿用原实验。

## 新增传统RO的数学模型及解读

设 $m_{i,t+h}$ 是只使用已观测历史的预测，训练期样本外相对需求为 $r=d/\max(m,1)$。由训练残差计算全局均值μ与标准差σ。
需求不确定集合为 $\mathcal U_{it}(\Gamma)=\{\mathbf d: m_{i,t+h}\max(0,\mu-\Gamma\sigma)\le d_{i,t+h}\le m_{i,t+h}(\mu+\Gamma\sigma),\ h=1,\ldots,4\}$。
Γ是区间宽度系数，不是跨期共享的不确定性预算；本RO不做聚类，因此可以与不分组DRO直接对照。μ、σ描述集合边界，并未在集合上赋予概率分布。
令 $U_h=m_h(\mu+\Gamma\sigma)$，$B_h$ 为计划需求发生前的库存。
旧版鲁棒约束为 $(d_h-B_h)_+\le(1-\beta)d_h,\ \forall d_h\in\mathcal U$，等价于 $B_h\ge\beta U_h$。β取原版训练前推控制目标。
在这些约束下最小化非负持有库存；因目标对目标库存单调，最优目标取约束的最小值。旧版 $S_h=\beta U_h$，新版如上。令 $\widetilde I_0=I_t$，$q_h=\max(0,\lceil S_h-\widetilde I_{h-1}\rceil)$，$\widetilde I_h=\max(\widetilde I_{h-1}+q_h-m_h,0)$。仅执行$q_1$。
这是箱式集合下可分离、无固定订货成本的库存目标策略的解析鲁棒对应式，不声称求得原始含服务指标的全局多期随机最优解。四期计划采用预测路径，后续决策通过滚动反馈实现。
传统RO保护集合内的每个需求点；DRO保护分布模糊集内的最坏期望/概率。RO在集合内的逐期保护不等于测试总体服务保证：测试需求可能超出集合，首期也不受本轮订单控制。集合覆盖率见ro_test_coverage.json。

## 训练选参与可复现性

Γ先搜索0到8、步长0.025，再在所选点附近以0.001细化。选参表为ro_validation.csv；冻结文件先写入磁盘，再评估测试需求。
旧版：前推训练1–36/验证37–60及重置训练29–60/验证1–28均满足原服务门槛，选择重置库存需求比最小者；最终残差沿用原版全60期拟合。
重置折是训练数据内部的场景验证，包含较晚时期拟合、较早时期验证；它不是纯前向预测。测试Period_1重新起算，四期预测逐期吸收已经实现的测试需求。
冻结RO参数：Γ=1.098；μ=1.008740；σ=0.168145。
原有五种方法的完整数学模型见[原数学报告](../outputs_v4/REPORT.md)。聚类依据见[特征聚类说明](../docs/CLUSTERING.md)。本报告补充RO并列出六种方法完整测试结果。

## 文件与运行

从仓库根目录安装原版本requirements_v3.txt，然后运行：
```sh
python experiments/ro_extension/extend_with_ro.py --version demand_fill_v3
python experiments/ro_extension/verify_ro.py
```
summary.csv为六种方法汇总；results_by_period.csv为逐期结果；orders_*.csv为全部商品订单；detail_*.csv.gz为完整轨迹；decision_comparison_full.csv.gz为168,000行并列决策结果。Excel展示汇总及逐商品订单，HTML展示对比。工作簿重建命令见ro_extension/README.md。
