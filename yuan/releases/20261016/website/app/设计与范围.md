# 设计说明与交付边界

参考用户提供的“ReplenishmentLab”方案，采用轻量学术软件风格：灰白底、深青重点、蓝色对照、金色满足率/前沿。页面不堆积大表，不用彩虹色区分34个模型，也不为每个点永久画名称。当前模型突出显示，其他点悬停查看；95%参考线附近默认放大，可平移到其他方案。

## 参考内容如何落地

| 需求 | 本次实现 |
|---|---|
| 研究概览、算法原理 | 四条主要流水线＋融合/鲁棒方向目录，34方案真实指标；SPO属于广义DFL的说明 |
| 单商品库存动画 | 任意6000 SKU，最多4个方案叠加、28期播放、滑块紧贴图表、累计指标与库存流 |
| 预测曲线 | 已保存的19方案点预测；其余显示未接入，不捏造网络预测 |
| 6000商品汇总对比 | 34方案、服务/满足率/J任意横纵坐标、实际前沿与经验PCHIP，非理论前沿 |
| 数学排版 | 本地SVG及MathML，正文不依赖联网LaTeX库，可展开复制源码 |
| 数据探索 | 训练需求均值/CV/零需求比例、类别筛选、60+28期需求；20原始特征未内嵌 |
| 科研/教学模式 | 真实冻结数据与简单因果反事实推演完全分离，教学结果不进入主模型比较 |
| 导出与配置 | 当前曲线SVG、所选范围CSV和JSON配置保存；尚无配置导入控件 |
| Python接口 | 本版为可离线运行的静态快照，未接入实时训练或求解器；仅记录接口边界 |
| 运行时间、Regret | 不制造数据或不公平排行；缺少统一全流程计时与全知最优参照，本版不做此类排名 |

本地使用React与共享Recharts运行时，按需解压矩阵；没有为了使用技术名词而额外引入FastAPI、Plotly、D3或安装网络依赖。参考中“当期到货”的示例已改为本项目一期到货；四步预测严格按其生成时点对齐。
