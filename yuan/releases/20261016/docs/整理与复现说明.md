# 整理范围与复现边界

本版合并代码、中文模型说明、冻结补货轨迹和离线网站，详见[工程与版本说明](工程与版本说明.md)。保留个人29方案，Kristina最新6方案作为独立署名对照。桌面两个ML项目不纳入；个人历史DRO不展示，原工程不删除。

## 三种“复现”不要混为一谈

1. **指标复算**：35方案×6000商品×28期，读取既有正式订单/库存，检查时序与守恒，重新计算指标。这一项已完成。
2. **冻结权重推理**：5个SPO/直接决策模型，用原冻结权重和新推理代码回放真实测试，库存、订单、销量逐元素一致。这一项已完成；不是重新训练。
3. **从零训练**：新工程的29个人方案用24商品合成数据完成端到端检查；没有把29方案全部6000商品重训一遍。Kristina也没有在本轮重新训练。

精确测试记录在`verification/`，合成数据成绩不进入网站排名。新训练从原始Excel导入后独立运行，不借用历史结果当训练输出；网站和reference命令读取的恰恰是明确标注的历史正式结果。

## 历史附件

`reference/历史指标.json`保留旧29方案×3集合的87行记录，仅供追溯。SPO动作细化后的本版测试结果以`results/benchmark/`为准，不能把旧动作集合训练/验证指标套在新版本上。当前35个展示方案只比较完整测试28期；未伪造Kristina或细化版本缺失的训练集成绩。

`reference/来源清单.json`为早期算法提取记录；本版新增动作细化、信息屏蔽、工件哈希及网站整合以本版源码和CHANGELOG为准。完整正式训练复现还需固定环境、输入与所有中间选择记录。

## 其他限制

相同评价口径并不等于同一验证协议。测试曾用于历史开发，不是全新盲测。有限动作SPO是近似决策学习，有限步可微内层DFL也不是精确全局规划。本次工程整合本身不是新增学术方法。
