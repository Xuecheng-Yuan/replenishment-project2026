# 每个模型怎样决定补多少货

共同时间顺序：上期订单到货→本期需求发生→销量与期末库存→决定下期订单。
同一服务指标不等于同一训练协议；普通ML是先预测再决策，SPO学习有限动作成本，DFL通过决策损失微调概率网络。

实现：`replenishment/training/forecast.py`。

3. 加上验证集校准的风险缓冲，得到下一期目标库存。
4. 扣除当前期末库存，非负部分向上取整下单；提前期一期。

## 特征聚类 DRO · 服务反馈

实现：`partners/kristina/upstream/experiments/ro_extension/service_band_revision.py:run_budget`。

1. 只用训练资料拟合预测、分组与基础风险水位。
2. 观察本期真实需求，更新当前期末库存及累计服务计数。
