# 六种补货策略动画：服务水平95%附近

当前结果要求所有6000商品完整28期的正库存比例在95%–95.5%。历史需求满足率版本保留原结果与原选参规则。

双击[动画/index.html](动画/index.html)离线打开。可切换全部6000种商品、全部480种爆品、全部5520种长尾品和10个固定SKU。六个窗口同步播放，每种方法包含真实到货、需求、销量、失销、库存、四期预测与计划。第一期计划实际执行，后三期在以后重算。

P按每个商品每天期末库存严格大于0计数，分母6000×28；分类和SKU视图用于解释，不代替总体约束。需求满足率FR＝销量/需求；库存需求比J＝累计期末库存/累计需求，越低越好。

新版用训练文件全部60期最终拟合，独立测试文件28期，测试Period_1重新开始，原始库存和零初始在途，提前期1、缺货丢失。每天只读取已发生需求。

预测参数在原三轮训练验证中确定：1–24→25–36、1–36→37–48、1–48→49–60。反馈参数使用训练29–60拟合、1–28回溯重启留出，在P为95%–95.5%的候选中最小化J。该回溯检验拟合段在验证段之后，不作为向前预测成绩；三轮向前及重启12期前缀另外诊断。所有选参数值在测试回放前冻结。

基础水位保留训练切片保护包络，执行水位倍率λ根据剩余服务预算、训练残差和最近已发生的单步预测误差确定。目标中心95.25%；累计服务偏高时减少后续补货，偏低时提高。λ和下一期服务预算在动画决策栏、Excel“服务预算”及service_feedback.csv展示。λ可以小于1，基础DRO的β不能直接解释为执行后测试服务保证。

本次六种方法实际P约95.28%，按完整28期真实数据核实；99%以上高库存中间方案已撤下。历史版与新版按各自约束分别判断。
