# 六策略补货场景动画（2026-10-15）

李佳蔚汇报用动画。新增传统区间 RO，支持当前正库存服务版与历史数量满足率版，共六策略、两个版本。原 10 月 14 日演示保留在原目录。

## 打开与演示

下载仓库 ZIP 并解压，双击 `启动演示.cmd`，或用 Edge / Chrome 打开 [动画/index.html](动画/index.html)。在总控点击“打开六个同步窗口”，允许浏览器弹窗。GitHub 的 HTML 预览不运行网页，需下载后打开。

总控可切版本、选商品、播放/暂停、跳期、重播及调速，六个窗口同步更新。独立窗口较小时隐藏重复控件；用任务栏或 Alt+Tab 切回总控操作。小屏幕也可直接在总控观看六个面板。

建议先看爆品 SKU 2620 第 1 期（初始库存与首期缺货），再跳第 8 期比较订单和水位；另看长尾 SKU 3026 第 12 期。两版分别比较，不能混成同一张策略排名。

普通离线演示无需 Python、Node、CDN 或训练环境。若要用本地服务器，从仓库根目录运行：

```bash
python -m http.server 8790 --bind 127.0.0.1 --directory "汇报成果/2026-10-15"
```

然后打开 <http://127.0.0.1:8790/动画/index.html>。

Windows 自动排列六窗口：本机有 Codex 捆绑 Node/Playwright 时，可运行 `启动六窗口演示.ps1`。普通 Node 环境可安装 `playwright` 后执行 `node 启动六窗口.mjs`；脚本使用已安装的 Edge。关闭该次启动的浏览器即可结束。若未安装这些依赖，使用前述 HTML 入口即可。

## 文件与策略

- [场景动画](动画/index.html)：货架、小人往返、到货、购买及期末订货；内嵌数据，可单文件离线运行。
- [公式互动](动画/公式互动.html)：用小样本说明 SAA、W∞ DRO 和教学 RO，另列项目实际区间 RO 的两版公式。
- [数据快照](动画/data.json)：完整实验汇总及 10 个固定代表商品的轨迹。
- [两版六策略轨迹 CSV](动画/新旧六策略真实轨迹.csv)：便于逐期核对与二次分析。

六种策略：传统 (s,S)、零半径经验 SAA、不分组 DRO、爆品/长尾 DRO、特征聚类 DRO、传统区间 RO。

## 来源与指标

结果冻结于提交 [`77068473c96a907fef258147cc23d78659b0b46e`](https://github.com/Xuecheng-Yuan/replenishment-project2026/tree/77068473c96a907fef258147cc23d78659b0b46e)：

- 当前版：`experiments/rolling_dro_v3/with_ro/outputs_v4`。
- 历史版：`experiments/demand_fill_v3/with_ro/outputs_v4`。
- [两版六方法比较](../../experiments/version_comparison/COMPARISON.md)。

总成绩按全 6000 SKU × 28 期计算。R＝期末库存严格大于零的商品期数占比；FR＝总销量/总需求；J＝总期末库存/总需求。实际恰好卖完时，FR 可以为 100%，R 仍记为 0。表中平均期末库存是 6000 个商品的平均每日库存合计。

10 个代表商品按品类内编号固定位置选取，共享初始库存和实际需求；没有按方法成绩挑选。真实数值来自冻结的逐期记录，小人数量、步行、购物时点和货架图标缩放为示意，不能当成原始顾客到达数据。最后一期订单单列为第 29 期到货，未混入前 28 期在手库存。

当前正库存服务版中，传统 (s,S) 的库存最低；历史数量满足率版中，爆品/长尾 DRO 最低。DRO 并不必然优于 RO。公式互动的教学 RO 使用共同示例区间，与项目中由 μ、σ、Γ 构造并单独校准的实际 RO 区分。

## 验证

上传前核对两版共 12 份逐期明细、2,016,000 条商品期记录的库存流转、订单/水位规则和汇总指标；通过六个弹窗的新旧版、商品、周期、播放/暂停/重播同步及移动端检查。Windows Edge 已实际验证六个独立原生窗口。
