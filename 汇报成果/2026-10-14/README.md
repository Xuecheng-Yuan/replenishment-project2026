## 打开网站

### 最简单的方式

下载`补货方案对比网站_离线版.html`，双击并选择Chrome、Edge或Safari打开。查看图表、选择模型和查看周期回放不需要外部CDN。

分享、发布等需要在线服务的功能不属于离线浏览保证范围。浏览器也可能限制从本地文件发起的某些操作；遇到这种情况使用服务器版。

### 本地服务器方式

已有仓库时，先更新仓库，再在仓库根目录运行：

```bash
cd "汇报成果/2026-10-14/website"
python3 -m http.server 8789 --bind 127.0.0.1
```

浏览器打开<http://127.0.0.1:8789/>。保持终端运行，按`Ctrl+C`停止。

必须保留`website`中的JSON数据侧文件，不能只复制`index.html`。此版本包含完整静态网页及结果数据，不需要安装机器学习环境或重新训练。

## 结果口径

- 服务水平：期末库存严格大于0的SKU周期数，占全部SKU周期数的比例。
- Fill Rate：总销量除以总需求，按数量加权。
- 库存比J：总期末库存除以总需求，越小越好。

网站沿用当前冻结实验和模型展示筛选，不是本次上传时重新训练的结果。PPT中的历史Fill Rate约束实验明确单列，不与新版服务水平约束混用。共同测试口径不能消除不同模型训练校准协议的差异。
